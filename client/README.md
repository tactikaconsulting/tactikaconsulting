# Compra Inteligente - Landing Page

Landing page para el servicio de asesoría de decisiones de compra "Compra Inteligente" de Tactika Consulting.

## 🚀 Características

- **Diseño Minimalista Nórdico**: Paleta limpia con azul profundo y verde menta
- **Responsive**: Funciona perfectamente en desktop, tablet y móvil
- **Rápido**: Construido con React 19, Vite y Tailwind CSS 4
- **Accesible**: Componentes shadcn/ui con soporte ARIA
- **SEO Friendly**: Metadatos optimizados

## 🛠️ Tech Stack

- **Frontend**: React 19 + TypeScript
- **Styling**: Tailwind CSS 4 + shadcn/ui
- **Routing**: Wouter
- **Build**: Vite
- **Package Manager**: pnpm

## 📦 Instalación

```bash
# Instalar dependencias
pnpm install

# Ejecutar en desarrollo
pnpm dev

# Build para producción
pnpm build

# Iniciar servidor de producción
pnpm start
